    Cómo programar un cartucho

    Un cartucho es JavaScript con tres funciones opcionales:

    function _init()   { }  // una vez, al arrancar
function _update() { }  // 60 veces por segundo: lógica
function _draw()   { }  // dibujar el fotograma

    Dibujo

pset(x,y,c)  pget(x,y)     circ(x,y,r,c)     circfill(x,y,r,c)
line(x0,y0,x1,y1,c)        print(txt,x,y,c,escala)   textw(txt)
